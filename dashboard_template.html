Valley Fever forecasts for California's ten highest-burden counties

Counties ranked by total cases with the best model and average error for each feature set

How to read the errors. RMSE and MAE are averaged over every forecast month in every rolling window, on the log-change scale the project uses (month-to-month change in the log of cases per 100,000). Smaller is better. Improvement is measured against the seasonal-naive baseline at the same horizon. Each section's summary line also gives the error in cases per 100,000, and the chart shows rates.

Feature sets. Environment uses weather, air quality, fire and pesticide data. Media uses California-wide article and tweet measures, so every county sees the same media signal. Media + environment uses both. All three include the county's recent case changes. Feature importance is averaged over every fitted window of the best model that reports it (Ridge, Random forest, XGBoost or SARIMAX). SARIMAX importance covers only its five chosen outside predictors, because it models past cases itself. If the LSTM or the baseline is best, the importance comes from the best of the other four models. Findings are predictive and associational, not causal.
